PulseBoard API

Clean Architecture · SignalR · CQRS · SQLite

Metrics

GET / Health check
POST /metrics Record a metric
GET /metrics Get metrics (paged, filterable)

Dashboards

POST /dashboards Create a dashboard
GET /dashboards Get active dashboards
GET /dashboards/{id} Get dashboard by ID
PUT /dashboards/{id} Update a dashboard
DEL /dashboards/{id} Delete a dashboard

Realtime

WS /metrics-hub SignalR hub (subscribe, unsubscribe)

Architecture

Domain → Application (CQRS) → Infrastructure (EF Core, SignalR) → Api (Minimal API)
