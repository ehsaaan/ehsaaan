Dispatch API

Clean Architecture · Polly Resilience · Background Jobs · Notifications

Jobs

POST /jobs Schedule a job
GET /jobs Get pending jobs (filterable, paged)
GET /jobs/{id} Get job by ID
POST /jobs/{id}/cancel Cancel a pending job

Notifications

POST /notifications Send notification (email, sms, push)
GET /notifications Get notifications (filterable, paged)

Architecture

Domain → Application (CQRS) → Infrastructure (EF Core, Polly, BackgroundService) → Api (Minimal API)
